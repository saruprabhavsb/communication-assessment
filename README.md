# CommAssess Pro 🚀

### AI-Powered Communication Assessment & English Learning Platform

CommAssess Pro is a full-stack AI-powered platform designed to help students and job seekers improve their **English communication, speaking, reading, vocabulary, grammar, group discussion, and interview skills** through interactive practice and personalized AI feedback.

**[Open CommAssess Pro](https://communication-assessment.ai.studio/)**

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/saruprabhavsb/Communication-Assessment.git
```

### 2. Open the Project

```bash
cd Communication-Assessment
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and configure the required values:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```

> **Security:** Never commit `.env` files, database credentials, JWT secrets, or API keys to GitHub.

### 5. Start the Application

```bash
npm run dev
```
